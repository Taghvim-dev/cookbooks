# Python examples

Requires the [Taghvim.dev Python SDK](https://github.com/Taghvim-dev/SDK) checked out into `../SDK`.

```bash
export PYTHONPATH=../SDK/python
export TAGHVIM_TEST_API_KEY="your-issued-test-key"
python python/convert_date.py
python python/widget_deadline.py
```

Do not run before receiving access; no self-service sandbox provisioning is claimed.
